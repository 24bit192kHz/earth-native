# User review preference

For every task that changes this project, deliver one concise, self-contained
HTML report with before/after evidence for each meaningful change. Include
matched images for visual changes, measurements for resource changes, and a
brief better/unchanged/worse/uncertain verdict. Cover discarded experiments and
material limitations. Clearly label unmeasured before states; never invent an
A/B result. Keep details collapsible and avoid external page dependencies.
